# 검수 목록

- 만든 뒤 하나씩 확인한다. `tools/simple_pt.py` 의 save() 경고는 0 이어야 한다.

## 장마다

- [ ] 제목 2–4 단어 한 줄, 부제 2 줄 이하, 빨간 줄 한 줄 하나.
- [ ] 한글 문장이 음슴체·단정형 (노트는 빼고).
- [ ] 그림의 축·범례·단위·캡션이 잘리지 않음, 흐리지 않음, 비율 그대로.
- [ ] 글·그림·쪽 번호가 겹치지 않음, 본문이 빨간 줄을 넘지 않음.
- [ ] 빨강은 빨간 줄과 그림의 핵심 한 곳뿐.
- [ ] 표 글자 14 pt 이상 — 작아지면 장을 나누거나 핵심 행·열만 남김.
- [ ] sim 숫자에 "(sim)" 표시, 측정과 섞지 않음.
- [ ] 식: IEEE 표기 (뜻을 나타내는 첨자·단위는 바로 선 글자), 번호 없음, = 자리 맞춤, where 2 줄 이하.

## 덱 전체

- [ ] 표지 빼고 모든 장에 쪽 번호, Appendix 는 A0·A1 ….
- [ ] 색인의 장 번호가 실제 장과 맞음 (save() 가 채운다).
- [ ] 장 수 ≈ 발표 분 − 1, 비교표가 본문에 있음.
- [ ] 같은 숫자가 장마다 같음 (부제·빨간 줄·그림·표).

## 파일

- [ ] `python check_setup.py` 가 모두 ✓ — △ 가 있으면 무엇이 달라지는지 (글꼴 대체 등) 알고 냄.
- [ ] PowerPoint 로 열림. Noto Sans KR 이 없는 PC 에서도 넘침·줄바꿈 없음 (한글은 맑은 고딕 등으로 바뀐다).
- [ ] 남에게 내는 파일은 노트를 지움 (`tools/fix_pptx.py --strip-notes`).
- [ ] 파일 속성 (작성자·회사) 에 개인 정보 없음 — simple_pt 는 비워 둔다.
