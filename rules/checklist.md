# 검수 목록

- 만든 뒤 하나씩 확인한다. `tools/simple_pt.py` 의 save() 경고는 0 이어야 한다.

## 장마다

- [ ] 제목 2–4 단어 한 줄, 부제 2 줄 이하.
- [ ] 한글 문장이 음슴체·단정형 (노트는 빼고). 영어 덱이면 마침표 없는 짧은 구.
- [ ] 그림의 축·범례·단위·글이 잘리지 않음, 흐리지 않음, 비율 그대로.
- [ ] 그림마다 무엇을 어떤 조건으로 잰 것인지 보임 (이름표·캡션·축·범례).
- [ ] 글·그림·쪽 번호가 겹치지 않음, 본문이 빨간 줄을 넘지 않음.
- [ ] 빨강은 빨간 줄·그림의 핵심 한 곳·표의 짚을 값뿐.
- [ ] 카드·회색 상자·큰 숫자 타일 없음. 상자는 채움 없는 검정 2¼ pt, 표는 논문식.
- [ ] 그림 없이 글만 있는 내용 장이 아님.
- [ ] 표 글자 14 pt 이상 — 작아지면 장을 나누거나 핵심 행·열만 남김.
- [ ] sim 숫자에 "(sim)" 표시, 측정과 섞지 않음.
- [ ] 인용은 [n] + 아래 참고문헌 줄.
- [ ] 식: IEEE 표기 (뜻을 나타내는 첨자·단위는 바로 선 글자), 번호 없음, = 자리 맞춤, where 2 줄 이하.

## 덱 전체

- [ ] 빨간 줄은 파트를 맺는 장에만 — Appendix 에는 없음.
- [ ] 부제가 질문과 평서문으로 적절히 섞임, 부제만 이어 읽어도 이야기가 됨.
- [ ] 같은 꼴이 연달아 이어지지 않음, 1·2·3 단계 번호를 대놓고 쓰지 않음.
- [ ] 표지·구분 장 빼고 모든 장에 쪽 번호, Appendix 는 A0·A1 ….
- [ ] 색인의 장 번호가 실제 장과 맞음 (save() 가 채운다).
- [ ] 장 수 ≈ 발표 분 − 1, 비교표가 본문에 있음.
- [ ] 같은 숫자가 장마다 같음 (부제·결론 줄·빨간 줄·그림·표).
- [ ] 본문 노트는 말할 대본만, Appendix 노트는 질문 받을 때 말할 거리.
