# 디자인 — 모양의 규칙

- 흑백 미니멀. 색은 정보를 구분할 때만 쓰고, 강조는 빨강 #B4161E 하나 (한 장에 한 곳).
- 모든 장에서 제목·부제·쪽 번호의 자리와 글꼴 크기가 같다.
- 값의 정본은 `tools/simple_pt.py` 맨 위 "디자인 값" 이다. 이 문서와 다르면 코드를 믿고 이 문서를 고친다.

## 목차

1. 원칙 — 메시지 하나, 장식 없음
2. 캔버스와 격자 — 16:9, 여백, 자리
3. 글꼴·크기·색 — 요소별 표
4. 면과 선 — 카드·표·구분선
5. 그림 — figstyle, 이름표·캡션
6. 표지 — 위에서 아래로
7. 레이아웃 — 장 종류와 simple_pt 함수

---

## 1. 원칙

- 그라데이션·장식 아이콘·화려한 도형·배경 이미지·그림자를 쓰지 않는다.
- 한 장에 메시지 하나, 굵은 결론 숫자 하나 (빨간 줄). 그림은 2–3 개까지 모아도 된다.
- 긴 문단을 넣지 않는다. 글이 넘치면 줄이거나 발표자 노트·Appendix 로 옮긴다.
- 제목·본문·그림 사이를 넉넉히 띄우고, 그림이 작아지지 않게 설명과 균형을 맞춘다.

## 2. 캔버스와 격자

- 16:9, 13.333 × 7.5 in = 1920 × 1080 px (1 pt = 2 px), 흰 배경.
- 좌우 여백 128 px (0.89 in) — 글·그림·카드의 왼쪽 끝을 이 선에 맞춘다.
- 제목 위 끝 72 px (0.5 in), 부제는 제목 바로 아래, 본문은 부제 아래 58 px 에서 시작해 920 px 에서 끝난다.
- 빨간 줄은 본문 아래 끝 (920 px) 에 붙인다. 쪽 번호는 오른쪽 아래 (아래 끝 1016 px).
- 칸 사이: 그림 3 칸·카드 32 px, 그림 2 칸·그림과 불릿 64 px.

## 3. 글꼴·크기·색

- 영문 Arial, 한글 Noto Sans KR (pptx 의 한글 글꼴 칸에 따로 적는다). 그래프 글자는 figstyle (Arial·Arial Narrow).

| 요소 | 크기 (pt / px) | 굵기·색 | 줄 높이 |
|---|---|---|---|
| 표지 제목 | 36 / 72 | Bold #111111 | 1.12 |
| 표지 위 작은 줄 (kicker) | 12 / 24 | Bold #767676, 대문자, 자간 2 pt | 1.3 |
| 표지 이름 / 소속 | 16 / 32 | Bold #111111 / #767676 | 1.3 |
| 장 제목 (2–4 단어, 한 줄) | 26 / 52 | Bold #111111 | 1.15 |
| 부제 (결론 한 문장, 최대 2 줄) | 20 / 40 | #4A4A4A | 1.3 |
| 본문 불릿 | 16 / 32 | #1F1F1F | 1.45 |
| 그림 칸 이름표 | 14 / 28 | Bold #111111 | 1.3 |
| 카드 소제목 / 카드 본문 | 16 / 32, 14 / 28 | Bold #111111 / #1F1F1F | 1.4 |
| 표 | 14 / 28 | 머리 줄 Bold, #1F1F1F | 1.3 |
| 캡션 | 12 / 24 | #4A4A4A | 1.4 |

## 4. 면과 선

- 카드: 채움 #F5F5F3, 테두리 #E5E5E3 0.75 pt, 모서리 4 pt, 안쪽 여백 36 px.
- 표: 머리 줄 #EDEEE9, 나머지 흰색, 격자 #CFCFCF 0.75 pt, 칸 여백 위아래 10·좌우 16 px. 이 연구가 나은 칸만 굵게.
- 구분선: #D9D9D9 0.75 pt.
- 그림자·굵은 테두리·진한 채움은 쓰지 않는다.

## 5. 그림

- 그래프는 figstyle (6 × 4 in, 300 dpi) 로 그려 PNG 로 넣는다. 비율을 지키고 칸 왼쪽에 붙인다.
- 그림 칸마다 위에 영어 이름표, 아래에 "무엇을 봐야 하는지" 캡션 한 줄 (한글).
- 축·범례·단위·캡션이 잘리지 않게 한다. 복잡한 그림 위에 글을 덮지 않는다. 없는 자료는 점선 상자에 "자료 대기".
- 그림마다 대체 텍스트 (alt) 를 단다.

## 6. 표지

- 위에서 아래로: 작은 대문자 회색 줄 → 짧은 검정 가로선 (326 × 6 px) → 큰 제목 (두 줄까지) → 회색 부제 → 이름 (굵게)·소속 (회색) → 맨 아래 날짜 (회색 작은 글씨). 가운데 높이에 모은다.
- 표지에는 쪽 번호를 달지 않는다.

## 7. 레이아웃

| 이름 | simple_pt | 모양 | 쓰는 곳 |
|---|---|---|---|
| A 그림 + 설명 | `figure_bullets` | 왼쪽 그림 (폭 약 50 %), 오른쪽 불릿 3–5 개 | 동기·목표·Appendix |
| F 그림 여러 개 | `panels` | 그림 1–3 칸 나란히, 칸마다 이름표·캡션 | 결과·견고성 |
| E·G 카드 | `cards` | 카드 2–3 개 (소제목 + 불릿 2–4 개) | 아이디어·선택지 |
| C 표 | `table` | 전체 폭 표 (폭 지정 가능) | 비교·사양 |
| H 요약 | `summary` | 얇은 선 아래 3 단 열, 회색 마무리 문장 | 결론 |
| 색인 | `appendix_index` | 질문 \| Appendix \| 장 표 (8 줄이 넘으면 둘) | Appendix 첫 장 |

- 요약·색인을 뺀 모든 장의 맨 아래에 빨간 줄 하나.
